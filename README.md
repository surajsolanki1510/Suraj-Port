# Suraj Port

Dark anime / cyber-fire portfolio — cinematic scroll, flame hero, Gen-Z HUD energy.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Personalize

Edit everything in one place:

- [`src/data/content.ts`](src/data/content.ts) — name, skills, projects, about, socials
- Portrait: `public/suraj-main-anime.png`

## Deploy (Vercel free)

1. Push this repo to GitHub
2. Import the repo at [vercel.com](https://vercel.com)
3. Deploy — you get a free `*.vercel.app` URL
